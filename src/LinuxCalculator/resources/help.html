Calculator

This independent Linux application recreates the Windows 7 Calculator interface using Microsoft's MIT-licensed calculation engine.

Standard calculator

Type numbers and +, -, *, /, or use the buttons. Enter or = calculates the result. Esc clears the calculation; Delete clears the current entry; Backspace removes a digit; F9 changes its sign.

MC clears memory, MR recalls it, MS stores the displayed value, and M+ / M− add to or subtract from memory. Copy and Paste are under Edit. Digit grouping is under View.

Additional legacy modes and panels are being implemented. Actions not yet available in this development build are disabled. Modern is reserved for later additions.
